# transition-public

## Transition API

Code for [Transition](https://github.com/chairemobilite/transition)'s API is generated by [Orval](https://orval.dev)
from Transition's OpenAPI spec:

- [common](./common/README.md): Zod schemas, shared by the frontend and the backend
- [backend](./backend/README.md): HTTP client and types, as only the backend calls Transition

Do not edit the generated files: regenerate them instead, e.g. when Transition's API changes.

### Regenerate

1. Serve Transition's OpenAPI spec on http://localhost:4321
2. Generate the code of both packages:

   ```sh
   npm run gen:transition-api
   ```
