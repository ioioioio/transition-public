# backend

## Transition API

The client, types and Zod schemas for [Transition](https://github.com/chairemobilite/transition)'s API are
generated by [Orval](https://orval.dev) from Transition's OpenAPI spec into
[./src/transition/generated/](./src/transition/generated/). The client reads Transition's address from the
`TRANSITION_ENDPOINT` environment variable, set in the root `.env`.

Do not edit the generated files: regenerate them instead, e.g. when Transition's API changes.

### Regenerate

1. Serve Transition's OpenAPI spec on http://localhost:4321
2. Generate the code:

    ```sh
    npm run codegen
    ```
